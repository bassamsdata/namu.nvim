01
Installation
A small setup. Useful defaults.

  
vim.pack.add({
  { src = "https://github.com/bassamsdata/namu.nvim" },
})

require("namu").setup({})

vim.keymap.set("n", "<leader>ss", "<cmd>Namu symbols<cr>", {
  desc = "Namu symbols",
})
{
  "bassamsdata/namu.nvim",
  cmd = "Namu",
  main = "namu",
  opts = {},
  keys = {
    { "<leader>ss", "<cmd>Namu symbols<cr>", desc = "Namu symbols" },
  },
}
Before you start
Neovim 0.11+
Use 0.12+ for built-in vim.pack.
A language server
For LSP symbols, workspace search, and call hierarchies.
Optional extras
Tree-sitter parsers, Universal Ctags, and a Nerd Font for icons.
vim.pack documentation

  
Open a file with an attached language server and run :Namu symbols. Tree guides and manual jump labels are ready to use.

In Neovim: :Namu sidebar opens symbols or your last transferred list; :Namu sidebar symbols returns to live symbols. :Namu bookmarks opens favorites. Save from a picker with Ctrl b, or send its results with Ctrl s.

  
This browser example saves favorites on this device. Neovim saves its own file locations and sidebar views across restarts. Read the sidebar recipe.





  
03
Keep your hands on the keys
Filter, preview, select, act.

  
Navigation
Ctrl n / ↓Next item
Ctrl p / ↑Previous item
EnterSelect item
;Toggle jump labels
EscLeave jump mode, then close
Tab / Shift TabSelect / unselect
Ctrl a / Ctrl lSelect all / clear selection
Actions
Ctrl yYank symbol text
Ctrl dDelete symbol text
Ctrl v / Ctrl hVertical / horizontal split
Ctrl qSend to quickfix
Ctrl sSend to sidebar
Ctrl bSave to favorites
Ctrl oAdd to CodeCompanion
Ctrl tAdd to Avante
Actions depend on the picker. CodeCompanion and Avante require their corresponding plugins.





  
04
Make it your own
Shared settings, with overrides for each picker.

  
Put shared options under global. Use a module such as namu_symbols to tune that picker. Your module settings take precedence.
Full configuration guideModules, defaults, options, highlightsConfiguration recipesJump keys, windows, filters, local developmentDownload a starter configA copyable Lua table
require("namu").setup({
  global = {
    display = { format = "tree_guides" },
    jump = {
      enabled = true,
      toggle_key = ";",
      auto_activate = false,
    },
  },
  namu_symbols = {
    window = { max_width = 100 },
  },
  ui_select = { enable = false },
})
