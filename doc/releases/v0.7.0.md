- **Jump labels:** press `;` in a picker, then a label key to jump directly to a visible item. Enabled by default, with optional automatic activation. Thanks to [@themastersheep](https://github.com/themastersheep) for implementing this in [#65](https://github.com/bassamsdata/namu.nvim/pull/65)!
- **Tree guides:** the tree-guide display is now the default for symbol hierarchies. The `indent` format remains available.
- **Visible selection:** focused rows adapt to colorscheme backgrounds, including transparent pickers. Row and icon colors refresh when switching themes, without adding an underline.
- **Picker fixes:** improved raw-mode highlights, completion handling, and call hierarchy requests, plus clearer picker titles.

To keep the previous defaults, set `global.jump.enabled = false` and `global.display.format = "indent"`.
